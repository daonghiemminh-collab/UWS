# UWS Guide & Documentation

Hệ thống Unifiable Workspace System hỗ trợ:
1. **Web PowerShell Terminal**: Tương tác terminal thời gian thực.
2. **File Explorer**: Duyệt cây thư mục tự do, tạo và xóa tệp.
3. **Notepad Editor**: Mở và lưu code trực tiếp với phím tắt Ctrl+S.
4. **Telemetry Monitor**: Đo hiệu năng CPU, RAM, GPU, Disks.
